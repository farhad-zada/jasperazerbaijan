# Official Website of Jasper Azerbaijan

This project is built with **Next.js** and follows a structured file organization to ensure maintainability and scalability.


## Technologies Used

- **Next.js** – React framework for building server-side rendered applications.
- **Tailwind CSS** – Utility-first CSS framework for styling.
- **Custom Hooks** – Encapsulated logic inside reusable hooks.

## Installation

To set up the project locally, follow these steps:

After cloning repostory:

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000` in your browser.

## Folder Breakdown

- **`app/`** – Contains pages and global layout files.
- **`components/`** – Stores reusable components.
- **`datas/`** – (Placeholder) For managing data-related logic.
- **`public/assets/`** – Static assets like images and icons.
- **`utils/hooks/`** – Custom hooks for modular logic.
